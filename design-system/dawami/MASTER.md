# Dawami Design System — MASTER

مرجع تصميم دوامي المعتمد، جرى تحديثه باستخدام المهارات الخمس التي قدمها المستخدم. شُغّل ui-ux-pro-max مع --design-system و--persist بعد مراجعة النتائج، وطُبّق إطار brand وطبقات design-system. تعليمات ui-styling وdesign مقروءة وجاهزة للتنفيذ في مرحلة الواجهات؛ لم تُنشأ واجهات أو أيقونات بعد.

الحالة: مواصفات معتمدة؛ التطبيق والتحقق البصري والتباين لم تُنفذ بعد. الرجوع لهذا الملف في كل مرحلة واجهات.

## تعديلات ملزمة تتقدم على النص المنقول

- أرقام غربية 0-9 افتراضياً مع خيار الهندية.
- الفاتح افتراضي، والداكن اختياري وفق اختيار المستخدم.
- ألوان الحالات ليست بالضرورة ألوان نصوص: درجات #16A34A و#D97706 على الأبيض تحتاج تغميقاً للنص العادي. نتحقق من كل زوج نص/خلفية في الفاتح والداكن إلى 4.5:1؛ لا نعتبر الجدول الأصلي اجتاز الفحص.
- نطاق المشروع يستبعد الكشك وأجهزة البصمة القديمة، ويشمل الهوية ذات العضويات والعملات المتعددة للشركات.
- المهارات متاحة محلياً ضمن work/provided-skills. التوليد الخام محفوظ في work/design-review للمراجعة؛ هذا الملف يضم المواصفات المعتمدة وتصحيحات المستخدم ويتقدم على توصيات الأداة العامة.

## النص المرجعي المنقول من الخطة الأصلية
## 7. نظام التصميم والهوية (من skills: ui-ux-pro-max + brand)

### 7.1 نتيجة `ui-ux-pro-max` وتعديلاتي
- **الأسلوب:** Minimalism & Swiss — نظيف، وظيفي، تباين عالي، مناسب للوحات التحكم والأدوات المهنية. الحركة خفيفة جداً (motion 2/10)، الكثافة متوسطة-عالية (7/10) للوحة المدير.
- **الوضع:** فاتح افتراضياً، داكن اختياري (يتبع النظام أو يدوي). الأداة نفسها نبّهت "لا تخلي الداكن افتراضي".
- **الخط:** الأداة اقترحت Plus Jakarta Sans بس **ما فيه عربي** → رفضته. التوصية: **IBM Plex Sans Arabic** (عربي + لاتيني متناسقين، أرقام واضحة للجداول)، self-hosted ومقصوص. البديل من قاعدة بيانات الأداة: Almarai.
- **الألوان (semantic):**

| الدور | فاتح | داكن | ملاحظة |
|---|---|---|---|
| primary | `#2563EB` | `#60A5FA` | أزرق ثقة (من الأداة) |
| on-primary | `#FFFFFF` | `#0B1220` | |
| background | `#F8FAFC` | `#0B1220` | |
| surface/card | `#FFFFFF` | `#111A2E` | |
| foreground | `#1E293B` | `#E2E8F0` | |
| muted-fg | `#475569` | `#94A3B8` | |
| border | `#E2E8F0` | `#1F2A44` | |
| danger | `#DC2626` | `#F87171` | |

- **ألوان حالات الحضور** (مع أيقونة ونص دائماً — ما نعتمد على اللون لحاله): بالوقت `#16A34A`، متأخر `#D97706`، غايب `#DC2626`، انصرف `#475569`، بإجازة `#7C3AED`، ما بلّش `#94A3B8`، عن بُعد `#0891B2`. رح أتحقق من تباين 4.5:1 لكل زوج بالمرحلة 1.
- **أزرار الحضور:** كبيرة (ارتفاع ≥ 72px، عرض كامل)، دخول بالأخضر وخروج بالـprimary/البرتقالي، مع حالة تحميل وحالة "بانتظار المزامنة".
- **قواعد:** لمس ≥ 44px، أيقونات SVG مو emoji، focus ظاهر، `prefers-reduced-motion`، بدون scroll أفقي على 360px.

### 7.2 طبقات الـtokens (`design-system` skill — التنفيذ بالمرحلة 1)
`primitive` (palette رقمية، مسافات، أحجام خط) → `semantic` (`--color-primary`، `--color-status-late`...) → `component` (`--btn-clock-height`، `--card-radius`...). الوضع الداكن = إعادة تعريف الـsemantic تحت `[data-theme=dark]`. **الوضع الخفيف** = `[data-lite]`: بيلغي الانتقالات والـblur والظلال، والرسوم بتتحول جداول بسيطة.

### 7.3 صوت الهوية (brand)
- **السمات:** واضح، محترم، قريب (شامي مهذّب)، مطمئن.
- **قواعد:** جمل قصيرة، فعل واضح بالأزرار ("سجّل دخول"، "ابعت الطلب")، خطاب مباشر مهذّب بدون تكلّف، الأرقام والأوقات دائماً واضحة.
- **رسائل الخطأ:** شو صار + شو تعمل: "أنت برّا نطاق الفرع (320 م). قرّب من الفرع وجرّب مرة تانية."
- **الإشعارات:** الاسم + الحدث + الوقت: "أحمد وصل 9:05".
- **المال والرواتب:** نبرة رسمية أكتر ودقيقة: "تم استلام المبلغ وإبراء الذمة".
- **ممنوع:** لوم العامل، مصطلحات تقنية، علامات تعجب كتير، إيموجي بالواجهة.

## تطبيق المهارات المقدمة — سجل المراجعة

- ui-ux-pro-max: الاستعلام الأول workforce attendance dashboard minimal أعاد لوحة سوداء/ذهبية لا تطابق الهوية؛ أعيد مرة واحدة بالاستعلام enterprise SaaS dashboard. النتيجة SaaS (General)، Minimalism & Swiss Style، primary #2563EB وbackground #F8FAFC، مطابقة للاتجاه المعتمد. التوليد بحركة 2 وتنوع 3 وكثافة 7. الأداة الحالية تسمي كثافة 7 Standard، فلا ندعي أنها ولّدت وضع كثافة أعلى.
- نُفّذ --persist إلى work/design-review دون --force. أصل ملفات ZIP لم يتغير. في النسخة المحلية فقط أضيف بديل Windows rename عند تعذر hard link؛ يحافظ على عدم استبدال ملف موجود. المخرج الخام ليس بديلاً عن قرارات المستخدم.
- Plus Jakarta Sans غير معتمد؛ الخط يبقى IBM Plex Sans Arabic. Hero + Features + CTA خاص بصفحات تسويق وليس لوحة العامل أو المدير؛ لا يُطبّق على واجهات العمل. لا تُضاف GSAP لمجرد اقتراح snippet؛ الحركة البسيطة والوضع الخفيف ومراعاة تقليل الحركة كافية ضمن النطاق المعتمد.
- لم تُثبت هذه المهارات عالمياً في حساب المستخدم؛ نسخها المحلية ضمن مساحة المشروع متاحة للمراحل القادمة.

## صوت دوامي — تطبيق brand

| السمة | التطبيق | مثال |
| --- | --- | --- |
| واضح | الفعل والنتيجة بجملة قصيرة | سجّل دخول |
| محترم | وصف الحالة دون لوم | ما اكتمل تسجيل الخروج. جرّب مرة تانية. |
| قريب | شامي مهذب في المساعدة | أنت برّا نطاق الفرع (320 م). قرّب وجرّب مرة تانية. |
| دقيق | لا ادعاء اعتماد عملية لم تزامن | بانتظار المزامنة |

الحضور والمساعدة بنبرة بسيطة؛ الرواتب والإقرار بنبرة رسمية دقيقة. أمثلة الإشعارات: أحمد وصل 9:05. لا نُظهر «تم استلام المبلغ» قبل التحقق الخادمي وإتمام الإقرار. أخطاء GPS لا تسمي العامل متلاعباً.

## مواصفات tokens — تطبيق design-system

هذه مواصفات وثائقية، وليست CSS أو مكونات منفذة.

| الطبقة | الغرض | مثال مرجعي |
| --- | --- | --- |
| primitive | قيم اللون والمسافات والخط | blue-600 = #2563EB؛ مقياس 4، 8، 16، 24، 32، 48، 64px |
| semantic | معنى مشترك يدعم الثيم | primary → blue-600؛ surface وforeground وstatus-on-time |
| component | مواصفة مكوّن تستخدم الدلالات | clock-button-background → status-on-time؛ clock-button-height = 72px |

لا raw hex داخل المكونات. الثيم الداكن يبدّل semantic، والخفيف يلغي الحركة والblur والظلال الثقيلة. ارتفاع لمس 44px حد أدنى عام، وأزرار الحضور 72px. body افتراضي 16px مع قياس التفاف العربية في التنفيذ.

| الحالة | مواصفة مكونات الحضور والطلبات |
| --- | --- |
| عادي | عنوان فعل واضح ونص وأيقونة SVG |
| تركيز | حلقة focus مرئية وغير مقصوصة |
| جارٍ التنفيذ | مؤشر ونص مفهوم ومنع التكرار دون فقد سياق التركيز |
| بانتظار المزامنة | يميز الحفظ المحلي عن اعتماد الخادم |
| خطأ | تفسير قريب من العنصر وخطوة تصحيح |
| معطل | سبب واضح، ولا اعتماد على اللون وحده |

مراجعة التباين 4.5:1 لكل زوج نص وخلفية، والتجاوب عند 360px، والاختبارات البصرية والتنقل بلوحة المفاتيح تبقى أعمال المرحلة 1. لا نتيجة فحص تباين شاملة أو واجهات مكتملة في هذه المرحلة.
