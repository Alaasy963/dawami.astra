# المرحلة 1 — حالة التنفيذ

25 أكتوبر 2026. هذه نسخة تطوير وليست إعلان اكتمال المرحلة. موافقة المستخدم على البدء والقيم الافتراضية محفوظة؛ وثيقة المرحلة 0 سجل تخطيط تاريخي.

## نتائج التنفيذ

- بناء TypeScript وVite وWorkbox ناجح. الكاش لملفات الواجهة فقط، دون API أو خرائط خارجية.
- 7 اختبارات Vitest ناجحة، بينها سيناريو متعدد الخطوات لمسارات Hono الفعلية عبر شركتين وقاعدة SQLite مؤقتة: التسجيل، PIN المؤقت، النطاق، الحضور، الدعوات، الاستعادة، CSRF، تعليق الشركة، حفظ الأوفلاين للمراجعة وتدقيق المالك.
- الاختبار يثبت رفض تعديل/حذف التدقيق، واستعادة المدير العام بحدث واحد دون PIN في السجل. بدائل KV وrate داخل الذاكرة لا تختبر حدود Cloudflare.
- واجهات الدخول، لوحة اليوم، العمال واستيراد Excel بمعاينة، الفروع والأقسام، الأجهزة، الإعدادات، الإشعارات والمالك مبنية. يلزم التحقق البصري والوظيفي بالمتصفح.
- أساس أوفلاين: سياق العامل المربوط بنفس التبويب حتى انتهاء الجلسة وطابور Dexie، مع إعادة التحقق بالخادم عند الاتصال.

## ما بقي قبل قبول المرحلة

- تشغيل Cloudflare وقياس CPU لتجزئة scrypt؛ لا ادعاء ملاءمتها لسقف Free.
- تجهيز VAPID واختبار push فعلياً؛ تعدد عضويات اشتراك push على الجهاز نفسه يحتاج معالجة.
- اختبار RTL والتباين و360px والأوفلاين والتثبيت بالمتصفح، وأيقونات PNG.
- شاشة حسم أحداث الأوفلاين؛ حالياً تحفظ للمراجعة دون تحويلها لجلسات.
- شعار الشركة، الإنجليزية والوضع الخفيف، وتجديد الجلسة الكسول.
- تقوية التزامن لموافقات الأجهزة وخروجين متزامنين وحجز outbox عند تداخل Cron، واستكمال مصفوفة الصلاحيات وضبط تكرار الجهاز بين هويتين.

## حدود التحقق

Wrangler أعلن الاستعداد لكن الاتصال من بيئة التنفيذ انتهى بـETIMEDOUT. Edge headless تعذّر تشغيله داخل sandbox. لم ننتج معاينة بصرية موثوقة ولم ننشر على workers.dev. لا توجد أسرار أو موارد Cloudflare فعلية في المستودع.

## دليل التجربة

بعد تشغيل README: أنشئ شركتين، وفرعاً بإحداثيات جهازك وعاملاً؛ غيّر PIN العامل واربط الجهاز وسجّل الحضور؛ راجع إشعارات المدير. أضف رقم العامل للشركة الثانية واقبل الدعوة بهويته العامة، ثم استعد PIN من الشركة الأولى وتحقق أن جلسته المؤقتة لا تنتقل للثانية. اختبارات الهاتف وPush والقفل تكمل بعد الربط.

مرجع Workbox: https://developer.chrome.com/docs/workbox/modules/workbox-build
