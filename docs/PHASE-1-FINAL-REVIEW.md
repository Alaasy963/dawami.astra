## قياس Cloudflare الحقيقي

عينة واحدة لكل مسار عبر wrangler tail مع فلتر محلي لطلبات الاختبار، دون نشر أسرار أو بيانات المستخدمين:

| المسار | CPU ms | زمن Worker ms | زمن العميل ms | النتيجة |
|---|---:|---:|---:|---|
| auth/login | 175 | 321 | 412 | ok / 200 |
| auth/me | 1 | 95 | 137 | ok / 200 |
| attendance/mine | 2 | 109 | 125 | ok / 200 |
| health | 0 | 0 | 38 | ok / 200 |

هذه عينة تشخيص وليست اختبار حمل أو p95. مسار الدخول يستخدم scrypt؛ لم يجر profiling لعزل كل جزء من CPU، فلا ننسب كل الوقت قطعياً إليه. لا تعادل مدة اتصال العميل استهلاك CPU.

Cloudflare يوثّق 10ms CPU لكل طلب على Workers Free، وقد يسمح بتجاوزات متفرقة قبل إنهاء التنفيذ عند التكرار. نجاح الدخول الحالي ليس ضماناً للاستقرار على Free. لا نخفض إعدادات تجزئة كلمات السر لتلائم الخطة. يلزم اختيار Workers Paid قبل الاستخدام الفعلي، أو إعادة تصميم المصادقة على خدمة مناسبة ثم إعادة اختبارها. لم يُغيّر الاشتراك أو الفوترة.

المصدر: https://developers.cloudflare.com/workers/platform/limits/
