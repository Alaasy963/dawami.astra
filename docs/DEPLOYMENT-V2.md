# dawami.v2 — نشر نسخة مستقلة

26 أكتوبر 2026

الرابط: https://dawami-v2.dawami-app.workers.dev

نُشرت نسخة مستقلة باسم Worker `dawami-v2` باستخدام `wrangler.v2.toml`، دون تعديل موارد النسخة القديمة `dawami`. الاسم الظاهر وعنوان الصفحة وأيقونة التثبيت: `dawami.v2`.

- قاعدة منفصلة `dawami-v2-db`، وترحيلات 0000–0008 مطبقة بنجاح.
- namespace منفصل للجلسات، وbindings منفصلة لمعدل الطلبات.
- الصفحة وhealth وmanifest رجعت HTTP 200؛ إنشاء شركة اختبار تقنية رجع 201، وقراءة جلسة المدير العام رجعت 200. حساب الاختبار ذو بيانات اصطناعية معزول داخل النسخة الجديدة.
- جرى فتح صفحة الدخول العربية ورؤيتها في المتصفح. باقي مسارات الموبايل والأوفلاين واللغة الإنجليزية تحتاج اختبار قبول فعلي.
- مفاتيح VAPID جديدة أُنشئت في الذاكرة ورفعت كأسرار Cloudflare، دون حفظها في ملفات المشروع. هذا لا يثبت وصول إشعار فعلي للجهاز.
- لم تُغيّر الخطة أو إعدادات الدفع. نجاح طلب التسجيل لا يثبت أن تكلفة scrypt تبقى دائماً ضمن حد CPU بالخطة المجانية؛ قياس الأداء المتكرر ما زال مطلوباً.

## ما يلزم إكماله

- تفعيل R2 بواسطة مالك الحساب؛ Cloudflare رفض إنشاء bucket برسالة Enable R2 (10042). إعداد R2 معلّق بتعليقات في ملف النشر، ورفع الشعار يعرض رسالة واضحة بأنه غير متاح. بعد تفعيله، أنشئ `dawami-v2-storage` وأضف binding `STORAGE` ثم أعد النشر.
- إعداد `OWNER_PHONE` و`OWNER_HASH` كأسرار على Worker الجديد. لا يوجد حساب مالك افتراضي أو كلمة سر مشتركة. تسجيل الشركات يعمل ويمنح منشئ الشركة دور المدير العام.
- اختبار Push على جهاز حقيقي، ومراجعة بقية معايير قبول المرحلة الأولى.

إعادة النشر: `npm run deploy:v2`.

## إصلاح تسجيل الخروج — 26 أكتوبر 2026

أزرار الخروج الثلاثة كانت تستخدم GET بسبب اختيار الطريقة تلقائياً عند غياب جسم الطلب. أصبحت تستدعي signOut باستخدام POST صريح مع CSRF. نجحت 12 حالة اختبار والبناء، ونُشر الإصلاح على dawami-v2 (version cc9207c3-abb4-4c27-a36d-0dd8b2970127). تحقق مباشر بحساب اختبار: login 200، logout 200، وإعادة استخدام الجلسة المحذوفة 401، مع التأكد من وصول حزمة الواجهة الجديدة. قد تحتاج التبويبات المفتوحة سابقاً إعادة فتحها لتفعيل تحديث Service Worker.

## تحديد موقع الفرع — جاهز محلياً، بانتظار النشر

- إضافة/تعديل الفرع بالبحث الصريح عن عنوان عبر Photon، أو النقر على Leaflet، أو GPS مع نعم/لا قبل اعتماد النقطة. لا حفظ دون اختيار؛ لا إدخال إحداثيات يدوي مطلوب.
- API البحث محمي بجلسة وشركة فعالة وصلاحية GM/AM، حد طلبات لكل شركة، مهلة 10 ثوانٍ، وترشيح الإحداثيات غير الصالحة. البحث لا يعمل تلقائياً أثناء الكتابة. الفشل يترك اختيار الخريطة متاحاً.
- Photon public demo للاستخدام المحدود بالتطوير فقط؛ لا ضمان إتاحة. مصدر السياسة: https://github.com/komoot/photon . يجب تقييم مزود إنتاج عند زيادة الاستخدام. الخريطة/العناوين تتطلب اتصالاً.
- اختبارات API تشمل تحويل نتائج البحث واستبعاد النقاط الخاطئة وفشل المزود، إضافة لاختبارات الفرع السابقة. 14 اختباراً ناجحاً. لا اختبار iPhone فعلي لهذه الدفعة.
- النشر تعذر بسبب غياب اعتماد Wrangler صالح. يلزم تشغيل npx wrangler login محلياً ثم npm run deploy:v2. لا ترحيلات قاعدة بيانات جديدة.
